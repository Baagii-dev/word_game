# Хоёр утсан дээр онлайн 1v1 турших заавар

Онлайн 1v1 нь Firebase (`word-battle-443510`) дээр ажилладаг тул хоёр утас **интернэттэй**
(Wi-Fi эсвэл мобайл дата) байхад л болно — нэг сүлжээнд байх шаардлагагүй.

## 1. Бэлтгэл (нэг удаа)

```bash
git pull            # branch1-ийг татна
flutter pub get
flutter devices     # холбогдсон утаснуудын id-г харна
```

Шаардлагатай 3 файл repo-д байгаа эсэхийг шалга (байхгүй бол багийн хүнээс аваарай):
`lib/firebase_options.dart`, `android/app/google-services.json`, `ios/Runner/GoogleService-Info.plist`.

### Android утас
1. Тохиргоо → Утасны тухай → "Build number"-ыг 7 дарж Developer mode асаана.
2. Developer options → **USB debugging** асаана, USB-ээр холбоно, "Allow" дарна.
3. `flutter devices` дээр гарч ирэх ёстой.

### iPhone
1. Xcode → Runner төсөл → Signing & Capabilities → **Team** сонгоно (өөрийн Apple ID, үнэгүй).
2. Bundle ID `com.example.wordBattle` өөр хүнтэй зөрчилдвөл өөрчилнө (жишээ: `com.example.wordBattle.<нэр>`);
   гэхдээ Firebase-ийн iOS апп `com.example.wordBattle`-д бүртгэлтэй тул өөрчилсөн бол
   `flutterfire configure --project=word-battle-443510` дахин ажиллуулна.
3. iPhone дээр Settings → Privacy & Security → **Developer Mode** асаана, "Trust" хийнэ.

## 2. Аппыг хоёр утсан дээр суулгах

Хоёр терминал нээгээд тус бүрт:

```bash
flutter run -d <утас1-id>      # терминал 1
flutter run -d <утас2-id>      # терминал 2
```

(Эсвэл `flutter build apk --debug` хийж APK-г хоёр дахь Android руу дамжуулж суулгаж болно.)

## 3. Туршилтын алхам

| # | Утас 1 | Утас 2 | Хүлээгдэх үр дүн |
|---|---|---|---|
| 1 | Нүүр → **Онлайн 1v1** → ник "А" → Үргэлжлүүлэх | | "Өрсөлдөгч хайж байна…", дээд талд "Онлайн" |
| 2 | | 15 секундын дотор Нүүр → **Онлайн 1v1** → ник "Б" | Хоёулаа **нэгэн зэрэг** тулаан руу орно, өрсөлдөгчийн нэр харагдана |
| 3 | Үг бүтээж **Довтлох** | | Утас 2-ын "Та" амь буурна, утас 1-д өрсөлдөгчийн амь буурна |
| 4 | | Үг бүтээж **Довтлох** | Утас 1-ийн амь буурна, дээд мессежид "Б: ҮГ" гарна |
| 5 | Хоёр утсан дээр эхний самбар **ижил** үсэгтэй эсэхийг харна | | Ижил (ижил seed) |
| 6 | Нэгнийх нь амь 0 болтол (эсвэл 90 сек) | | Ялагч/ялагдагчид дүнгийн цонх гарна, ялагч +25 🪙, ялагдсан +5 🪙 |
| 7 | **Жагсаалт** | Мөн адил | Хоёр ник онооны жагсаалтад харагдана, "Онлайн жагсаалт" гэсэн тэмдэгтэй |

Нэмэлт шалгалтууд:
- **Гарах:** тулааны үед нэг утас дээр 🏳 дараад "Тийм" — нөгөө утсан дээр ялалтын цонх гарна.
- **Холболт тасрах:** нэг утсыг Airplane горимд оруул — ~20 секундын дараа нөгөө утас ялна.
- **Өрсөлдөгч олдохгүй:** зөвхөн нэг утсаар "Онлайн 1v1" дар — 15 секундын дараа bot-той тулаан эхэлнэ.
- **Дэлгүүр:** Нүүр → Дэлгүүр → бэлтгэл/дүр авна; "Coin авах" → туршилтын төлбөр (жинхэнэ мөнгө хасагдахгүй).
  Нэг утсан дээр авсан coin нөгөө утсан дээр **ижил ник/хэрэглэгчээр** нэвтэрвэл л харагдана
  (хэрэглэгч бүр анонимаар нэвтэрдэг тул өөр утас = өөр түрийвч).

## 4. Өгөгдлийг харах

Firebase console → Firestore Database:
https://console.firebase.google.com/project/word-battle-443510/firestore

- `users/{uid}` — ник, нийт оноо, ялалт
- `matches/{id}` — тулаан: төлөв, амь, сүүлийн үг, ялагч
- `wallets/{uid}` — coin, бэлтгэл, баатрын дүр, гүйлгээний түүх
