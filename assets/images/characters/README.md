# Дүрсийн зураг (сонголттой)

Энд баатар, дайсны PNG зургаа хийж болно (дүр бүр ил тод дэвсгэртэй, дөрвөлжин).

- Дайсны зураг: `assets/data/levels.json` дахь дайсан бүрийн `"image"` талбарт
  замыг нь бичнэ. Жишээ: `"image": "assets/images/characters/wolf.png"`.
  Талбар хоосон эсвэл файл олдохгүй бол emoji харагдана.
- Баатрын зураг: `lib/core/assets.dart` дахь `AppAssets.heroImage`-д замыг нь бичнэ.
  `null` бол кодоор зурсан баатар харагдана.
